# 스네이크 게임

HTML, CSS, JavaScript만으로 만든 브라우저 스네이크 게임입니다. 별도의 설치나 빌드 없이 `index.html`을 열면 바로 실행됩니다.

## 실행 방법

1. 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/cookyjy071-ctrl/snake-game.git
   ```
2. `index.html`을 브라우저에서 엽니다.
3. **게임 시작** 버튼을 누릅니다.

## 조작 방법

| 입력 | 동작 |
|---|---|
| 방향키 (↑ ↓ ← →) | 뱀 이동 방향 변경 |
| 일시정지 버튼 | 일시정지 / 재개 |
| 소리 버튼 | 효과음 켜기 / 끄기 |

## 게임 규칙

- 400x400 캔버스, 20x20 격자에서 진행합니다.
- 먹이를 먹으면 뱀이 한 칸 길어지고 **10점**을 얻습니다.
- 벽이나 자기 몸에 부딪히면 게임 오버이며, **다시 시작** 버튼으로 새 게임을 시작합니다.
- 이동 중인 반대 방향으로는 바로 꺾을 수 없습니다.

## 기능

- **난이도 선택**: 게임 중에도 바꿀 수 있습니다.

  | 난이도 | 이동 간격 |
  |---|---|
  | 쉬움 | 200ms |
  | 보통 (기본) | 150ms |
  | 어려움 | 100ms |
  | 매우 어려움 | 50ms |

- **레벨 시스템**: 50점마다 레벨이 오르고, 레벨이 오를 때마다 이동 간격이 10ms씩 줄어 더 빨라집니다. 간격은 20ms 아래로 내려가지 않습니다.
- **최고 점수 저장**: 최고 점수를 브라우저 LocalStorage(`snake-high-score`)에 저장해 새로고침 후에도 유지됩니다.
- **효과음**: 시작, 먹이 획득, 게임 오버 소리를 Web Audio API로 직접 합성합니다. 별도의 음원 파일은 없습니다.

## 파일 구조

```
Snake game/
├── index.html   # 화면 구성 (점수판, 컨트롤, 캔버스)
├── style.css    # 스타일
└── main.js      # 게임 로직, 그래픽, 소리
```

## 참고

- 최고 점수는 난이도와 관계없이 하나로 저장됩니다.
- 최고 점수는 브라우저와 접속 주소별로 따로 저장됩니다.
